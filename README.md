# 🚀 Tech Event Platform

## 📌 Project Overview

Tech Event Platform is a full-stack web application designed to simplify the discovery, organization, and management of technology-related events. It provides a centralized platform for students, developers, event organizers, and administrators to explore and manage technical events such as hackathons, workshops, webinars, coding competitions, and conferences.

## 🎯 Objectives

- Provide a centralized platform for technical events.
- Simplify event discovery and registration.
- Help organizers manage events and participants.
- Provide separate dashboards for different user roles.
- Encourage students to participate in technical activities.

## ✨ Key Features

- **Event Discovery:** Explore technology-related events.
- **Participant Dashboard:** Access personal events, schedules, and certificates.
- **Organizer Dashboard:** Manage events, registrations, and attendance.
- **Admin Dashboard:** Manage users, event approvals, and categories.
- **Event Management:** Create and organize technical events.
- **Responsive UI:** User-friendly web interface.

## ⚙️ Installation and Setup

### Prerequisites

- Node.js (20.9 or later)
- npm
- Code editor (VS Code recommended)

### Step 1: Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### Step 2: Navigate to Project

```bash
cd tech-event-platform
```

### Step 3: Install Dependencies

```bash
npm install
```

### Step 4: Start Frontend

```bash
npm run dev
```

Open your browser:

```text
http://localhost:3000
```

### Step 5: Start Backend

Open another terminal:

```bash
cd apps/backend
npm run start:dev
```
